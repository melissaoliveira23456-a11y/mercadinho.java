# 🛒 Sistema de Mercadinho em Java

## 📌 Sobre o projeto

Este projeto consiste em um sistema de gerenciamento de mercadinho desenvolvido em Java, como parte da minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas.

O objetivo é praticar lógica de programação e desenvolver funcionalidades para o gerenciamento de produtos e estoque.

## 🚀 Funcionalidades

- Cadastro de produtos.
- Listagem de produtos.
- Busca por código.
- Registro de vendas.
- Atualização automática do estoque.
- Relatório de estoque.

## 🛠️ Tecnologias utilizadas

- Java
- Apache NetBeans
- GitHub

## 📚 Conceitos praticados

- Variáveis e tipos de dados.
- Estruturas condicionais.
- Laços de repetição.
- Métodos.
- Classes e objetos.
- Listas com `ArrayList`.
- Entrada de dados com `Scanner`.

## 🎯 Objetivo de aprendizagem

Consolidar os fundamentos de Java por meio de um projeto prático, evoluindo gradualmente para aplicações mais completas.
